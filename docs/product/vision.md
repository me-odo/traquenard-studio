# Product vision

Traquenard Studio lets people compose, publish, and play generic party games across local or multi-device sessions. Authors manipulate comprehensible typed blocks and inspect reusable composites; they do not assemble kernel-sized operations. A future textual language and changing visual grammars must target the same canonical Game IR.

The first product proof is deliberately narrow: build or load a sequential interaction, validate and publish an immutable artifact, host a server-authoritative session, join ephemeral participants, and drive deterministic prompts. The simulator additionally executes a group vote and a private card round. Disconnect pause/resume and timer-freeze behavior are currently runtime semantics tested with trusted inputs; real WebSocket lifecycle wiring and a server scheduler remain a future integration step.

Non-goals include a marketplace, arbitrary package code, accounts, payments, native apps, a textual DSL, final connector/parallel UX, and distributed services.
