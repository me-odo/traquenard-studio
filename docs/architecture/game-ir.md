# Canonical Game IR v1

IR v1 is a serialized tree of discriminated operations with typed expressions, declared state, named composites with typed input/output ports, and audience intents. Composite implementations are isolated: they can access only declared ports and operation-local bindings, never implicit game globals or contextual participant state. Composite invocation explicitly binds argument expressions and output variables, so every dependency and result remains inspectable and statically checkable. Trees make sequence, condition, iteration, parallel barriers, and composite inspection explicit without inventing a full language. Stable IDs support editor projections and future migrations; coordinates never appear in IR.

Static validation resolves variables and expression types, recursively checks literal values (including empty and nested collections) against their declared types, rejects duplicate IDs, invalid input/options, unsafe or write-conflicting parallel children, invalid or aliased composite bindings, cyclic composite calls, missing required output assignments, missing composites, and unsupported versions before execution. Composite outputs are required results: every normally returning path assigns each one explicitly, while `end` may terminate execution without returning. Publishing canonicalizes the definition, pins asset-pack versions, assigns a game version, and computes a deterministic SHA-256 content hash. Canonical object keys use raw, unnormalized UTF-16 code-unit order, never locale-sensitive collation.

V1 parallel children are independent waits/presentations with non-conflicting writes and join with `all`; richer branch continuations can extend the versioned schema later. Audiences include both a scalar participant expression and participant collections, alongside the static everyone/host/team/role forms. Expressions are intentionally closed and side-effect free. A future textual DSL and alternate visual editors can serialize the same model.

Migration contract: readers dispatch by `irVersion`. V1 is the first persisted shape and has no meaningful production legacy, so bootstrap-era semantic corrections—including the scalar participant audience and stricter validation—are corrected in place. Artifacts published under the prior locale-sensitive canonicalization must be republished. Future discriminator or required-field changes after this bootstrap phase must add a reader/migrator rather than silently breaking stored drafts/artifacts.
