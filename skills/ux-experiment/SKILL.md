# UX Experiment

State one falsifiable usability hypothesis and evaluation criteria. Register an authoring experiment as the current authoring baseline plus explicit experimental axes. Use the standard Lab Harness and its reproducible device profiles, reuse baseline components, and override only what the hypothesis tests; never silently fork the whole editor. Build the smallest isolated prototype in the web Visual Lab or a replaceable view-model/component. Keep coordinates, connector shapes, colors, animation timing, and gesture mechanics outside canonical IR.

Use semantic compatibility from `authoring-domain`; communicate it through more than color. Provide a non-drag interaction where drag/drop exists and retain keyboard/semantic HTML paths. Predetermined runtime outcomes drive animations. Record unresolved experiments in a deduplicated GitHub Issue, not local todo documents, and avoid snapshotting rapidly changing editor canvases.

An experiment is not complete at recommendation time. Before closing its GitHub Issue, run the [Experiment Closure](../experiment-closure/SKILL.md) workflow.
